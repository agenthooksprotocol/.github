# Contributing

Thank you for contributing. Repository-specific instructions take precedence over these defaults.

## Before opening an issue

- Search existing issues and documentation.
- Use the issue form that best matches the request.
- Include a minimal reproduction, relevant environment details, and sanitized logs when reporting a bug.

## Pull requests

- Keep each change focused and explain both what changed and why.
- Link related issues when applicable.
- Add or update tests and documentation when behavior changes.
- Note compatibility concerns, follow-up work, and checks you could not run.
- Never include credentials, private data, or other secrets.
